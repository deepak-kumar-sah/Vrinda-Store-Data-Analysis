# Vrinda Store Data Analysis

## 📊 Project Overview

Vrinda Store Data Analysis is an Excel-based data analytics project focused on analyzing sales data to understand customer behavior, sales performance, order trends, and business growth.

The project uses Microsoft Excel for data cleaning, analysis, pivot tables, charts, and dashboard creation.

## 🎯 Objectives

- Analyze overall sales and order performance
- Understand customer purchasing behavior
- Identify top-performing states
- Analyze sales by gender and age group
- Identify popular product categories
- Analyze sales channels
- Find key business trends and insights
- Create an interactive sales dashboard

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Key Analysis

The project analyzes:

- Sales and order trends
- Orders by gender
- Orders by age group
- Sales by state
- Sales by product category
- Sales by channel
- Monthly sales performance
- Customer purchasing patterns
